# Feedback

Status: active

## Active Feedback Themes

- The existing page does not read as a production editor.
- The user wants a 3D engine editor, not a 2D editor.
- The viewport should own the screen.
- Panels should be compact draggable overlays that feel pulled in from off-screen.
- The left panel should be a compact Domain Stack, not a generic project/file tree.
- The bottom timeline should sequence and link events between kits, with each step able to drive a kit.
- Adding kits must use a registry-backed dropdown with visible sub-kits/domains, not a hardcoded append.
- Composite kit dropdown selections should show sub-kits before install without requiring the user to hunt through a hidden panel area.
