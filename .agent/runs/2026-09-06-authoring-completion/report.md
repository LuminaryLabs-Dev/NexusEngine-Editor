# Usable Authoring host delivery

The host installs and checks the real pinned Engine and all 19 Authoring kit
API owners. Source mutation uses Core Project transactions; local storage,
Canvas controls, Three preview, PNG/GLB encoding and worker threads remain
Editor-owned. No fallback runtime is used for Authoring. The legacy Editor
continues to pass intent, build and browser checks with the same Engine pin.

Validation: npm test passes strict nine-stage headless evidence tests, nine
Authoring host/export/render/UI/CLI/worker/IndexedDB/articulation/batch groups,
legacy intent tests, build and Playwright. Public clean consumption proves
all 19 Engine factory imports, the guide example, store reopen, texture GLB
export, independent browser rendering and packaged CLI. Exact locked npm-ci
installs match every one of the packed Engine's 1,886 files. Engine and Kits
commit/package identities are recorded in dependency-identities.json.

Actual asset, image hash, performance and deformation evidence is recorded
separately. Fifteen 10k/100k and 1K/2K/4K runs complete; heavy operations are
not realtime. Five donut views drove explicit UV, icing-edge and normal-strength
corrections. The final exported donut retains 26 editable source documents,
180 sprinkled instances, four textures and a camera/light; it validates without
errors or warnings. Organic skinning agrees with independent Three deformation
under nonidentity hierarchy within 2.69e-7 units.

Supported limitations are documented in AUTHORING.md and docs/AUTHORING-*.md.
This delivery is not full Blender compatibility, FBX, arbitrary shader graphs,
a general intersection solver, collaboration service or hundred-thousand-scene
production certification. The optional WebGPU providers remain candidate with
mock-device proof; they are not required by the Three/WebGL Authoring host.

Engine commit A and Kits commit B exist before this Editor commit C. A final
packed-consumer rerun and ordinary main pushes must verify the corresponding
remote identities. No deployment, tag, Actions execution, release or npm
publication is authorized by this workflow.
