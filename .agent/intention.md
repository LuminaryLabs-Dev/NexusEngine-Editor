# Intention

Status: active

Compose games by adding registered domains and kits to a validated hierarchy, editing a draft, applying it atomically, and proving the accepted selection in a disposable NexusEngine runtime.

The first screen remains a 3D engine workspace. Hero actions are Add, Apply, Run Once, Play, and Stop. NexusEngine owns registry and planning truth; the Editor owns visual composition and preview receipts. Source authoring and registry-package installation stay outside this browser workflow.
