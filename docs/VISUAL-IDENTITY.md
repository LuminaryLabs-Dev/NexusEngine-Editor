# Visual Identity

The identity represents the Editor's actual workflow: registered Domain and Kit
modules connect to a bounded 3D viewport, where they become an accepted scene
and validated playable output.

## Approved assets

- `assets/brand/logo-transparent.png` - primary transparent mark.
- `assets/brand/logo-256.png`, `logo-512.png`, `logo-1024.png` - fixed-size exports.
- `assets/brand/social-card.png` - repository and social preview.
- `assets/brand/cover-1280x640.png` - wide documentation cover.
- `assets/brand/manifest.json` - dimensions, generation settings, and hashes.

## Style

- Flat 2D technical paper collage, not photorealistic or sci-fi imagery.
- Deep navy identifies the editor boundary; cyan identifies composition flow.
- Green and amber identify accepted state and differentiated Kit groups.
- Keep all modules, arrows, viewport edges, and receipts fully inside frame.
- Preserve transparency for standalone logo use and never crop its module nodes.

The cover is a conceptual workflow diagram, not a literal UI screenshot. Real
product appearance is documented through the live editor and Playwright proofs.

Source and mask assets are retained so the pack can be reproduced through Repo
Image Studio. Validate the pack after every approved replacement.
